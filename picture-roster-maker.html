Picture Roster Maker

Turn a class list spreadsheet (with student photos) into a printable name-study sheet: photo + first name and last initial + major. Built for learning your students' names in the first week.

Runs entirely in your browser · the file is never uploaded anywhere
  1. Open your class list in AriesWeb. Sign in and go to the roster for the section you want.
  2. Download the Excel file with photos. The download choice that includes photos is the one you need — without them there is nothing to build a picture roster from.
  3. Load that file below. Your sheet appears right away, ready to print.

… or drag the file here. Works offline — nothing leaves this computer.
